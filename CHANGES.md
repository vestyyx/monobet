## Admin Phase 7 — Hardening & polish (committed)
- **Auth hardening** (`lib/auth.ts`): explicit better-auth `rateLimit` (window 60 s / max 100; the built-in special rules hold sign-in/sign-up to 3 attempts per 10 s per IP) and an explicit session lifetime (30 days, cookie refreshed at most daily). Verified live: 3× invalid sign-in → 401, 4th within the window → 429.
- **Security headers** (`next.config.ts`, every route): `X-Frame-Options: SAMEORIGIN` (SAMEORIGIN, not DENY — the rewards ad player is a same-origin iframe), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
- **Permission sweep**: script-verified every exported admin server action starts with a role gate (`assertRole`/`requireRole`/`requireAdmin` — 0 gaps in `actions-admin.ts`), and every API route is either gated (`/api/me`, `/api/notifications`, both CSV exports), the better-auth handler itself (rate-limited), or intentionally public. Destructive UI ops keep their `confirm()` dialogs; server actions remain CSRF-safe by Next.js design.
- **Market soft-delete** (`lib/actions.ts`): `deleteMarket` no longer wipes rows. Open positions are refunded at mark and their rows dropped (same lifecycle as a settle), then the market and its option children are marked `status: "deleted"` — the market row and the **full trade history survive** (previously they cascaded away). `listMarkets` filters by status so deleted markets vanish from player lists; the market detail page shows a Deleted badge; the admin markets desk gains a Deleted filter + badge (`MarketStatus` gains `"deleted"`, no migration needed — text column).
- **Players desk pagination** (`/admin/players`): 50 per page, offset-based, GET filters carried through prev/next links (server-rendered, works without JS); out-of-range pages clamp to the last page.
- **CZ/EN parity guard** (`lib/i18n.test.ts`): recursive key-set test asserting the CS dictionary has every EN key, no extras, and no empty strings — the "i18n in sync" working rule is now enforced by CI.
- **2-minute demo path** (`DEMO.md`): click-by-click stakeholder tour — dashboard → audited grant with reason → audit log → approvals → market resolve → books check + config rollback → CSV export → announcement banner, with reset notes.
- Verified E2E on the dev server with throwaway admin + player: security headers live on all routes; rate limit 401×3 → 429; market created → player bought Ɱ20 YES (trade + position + ledger) → admin deleted with confirm dialog + reason → `market.status='deleted'`, trade row kept, positions dropped, Ɱ20.07 refund at mark, `market.delete` audit (after: `deleted`); home keeps showing only the trade-ticker mention (no market card); detail page renders the Deleted badge; admin desk Deleted filter lists it; players `?page=2` clamps to 1 (pager hidden at one page).
